# Kunal Singh — Portfolio

Responsive DevOps and cloud engineering portfolio built as a lightweight static site for GitHub Pages.

## Publish

Create a repository named `kunal9038.github.io`, push these files to its `main` branch, and allow the included Pages workflow to deploy. The site will be available at `https://kunal9038.github.io/`.

## Contents

- `index.html` — page structure and portfolio content
- `styles.css` — responsive styling
- `script.js` — mobile navigation
- `.github/workflows/pages.yml` — GitHub Pages deployment
